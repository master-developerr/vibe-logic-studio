# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
College students, non-technical founders, creators, and freelancers who want to build and ship real, live websites using modern AI tools and practical development workflows, without prior programming experience.

## Product Purpose
Vibe Logic Studio delivers an immersive, outcome-first 7-day AI-assisted coding bootcamp ("Build Software with AI" / "AI Build Sprint"). The platform guides beginners from raw concept to published production software with live mentoring, interactive LMS curriculum, and cohort community.

## Positioning
"Think it. Build it. Ship it." Unlike theoretical video tutorials or passive online courses, Vibe Logic Studio is strictly outcome-driven: students build and deploy 4 real, responsive web projects in 7 days at an accessible ₹999 price point.

## Operating Context
- Live cohorts with daily progressive milestones.
- Real development toolchains: Next.js, React, Tailwind CSS, modern AI IDEs (Cursor, Lovable, Bolt.new, v0, Gemini).
- Dedicated WhatsApp community integration for cohort discussions and unblocking.
- Integrated LMS student dashboard for class recordings, assignments, and verified certificates.

## Capabilities and Constraints
- Next.js (App Router) frontend with strict TypeScript.
- Convex as the unified real-time database, serverless backend, and file storage.
- Clerk for authentication and role-based access control (Student, Admin).
- Razorpay for transaction processing with verified signatures, webhooks, and idempotent seat allocation.
- Route isolation: `/` (Studio homepage), `/build-software-with-ai` (original course landing page), `/ai-build-sprint` (redesigned dedicated course landing page), `/checkout`, `/dashboard`, `/admin`.

## Brand Commitments
- Signature dark studio aesthetic with `#171717` / `#1F1F1F` surface depths, `#FF5722` ember accent, and `#22C55E` success indicators.
- Authentic developer culture: real tool vectors, genuine terminal/code previews, no generic corporate stock imagery.
- Direct, transparent pricing: ₹999 all-inclusive launch pricing with 7-day money-back guarantee.

## Evidence on Hand
- Four real student-built production projects:
  - Diligence Live (`https://www.diligencelive.com/`) — Corporate and professional advisory (framing protected, verified snapshot).
  - TicketLelo (`https://www.ticketlelo.in/`) — Event technology and booking platform (live interactive embed).
  - KBG Advisory (`https://kbg-new.vercel.app/`) — Financial and strategic advisory (live interactive embed).
  - Sherhan Portfolio (`https://sherhan.site/`) — Creative direction and personal brand (live interactive embed).
- Verified student reviews from cohort alumni (Mira Nair, Nikhil Thomas, Aditya Rao).

## Product Principles
1. Outcome First: The primary metric of success is a live, published URL in production.
2. Production-Grade Toolchains: Teach modern engineering practices, not toy sandbox builders.
3. Radical Transparency: Real pricing, real tool costs, real student projects, and clear refund terms.
4. Frictionless Onboarding: Instant WhatsApp invite, direct checkout, and immediate cohort access.

## Accessibility & Inclusion
- High-contrast text compliance (≥4.5:1 on dark surfaces).
- `prefers-reduced-motion` fallbacks across animated marquees and motion elements.
- Semantic HTML tags, clear ARIA tab roles, and keyboard-accessible accordion panels.
